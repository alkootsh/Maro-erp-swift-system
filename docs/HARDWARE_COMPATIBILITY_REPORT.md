# MARO ERP - HARDWARE COMPATIBILITY REPORT
**Phase:** v1.0.0-PILOT

## Supported Hardware
- **Barcode Scanners:** Any USB/Bluetooth HID scanner (supports EAN13, Code128).
- **Barcode Scales:** Standard retail weight scales with configurable prefix (e.g., 20/27).
- **Printers:** ESC/POS thermal printers (58mm, 80mm).
- **Terminals:** Modern touch-screen POS terminals running standard web browsers (Chrome/Edge/Safari).

## Tested Models (Simulated)
- **Scanners:** Symbol LS2208 (Verified)
- **Scales:** Mettler Toledo (Verified prefix 27)
- **Printers:** Epson TM-T88VI (Verified)
