# كتاب 01: دليل التثبيت (Installation Guide) - منصة مارو للأعمال (MARO ERP)

## 1. مقدمة
مرحباً بك في دليل التثبيت الخاص بمنصة مارو للأعمال. هذا الدليل يغطي خطوات تثبيت وإعداد المنصة في بيئات العمل المختلفة.

## 2. متطلبات النظام
### متطلبات العتاد (Hardware)
| الفئة | المعالج | الذاكرة (RAM) | التخزين |
| :--- | :--- | :--- | :--- |
| متجر صغير | Core i3 | 8GB | 256GB SSD |
| متجر متوسط | Core i5 | 16GB | 512GB SSD |
| هايبر ماركت | Core i7/Xeon | 32GB+ | 1TB+ NVMe |

### البرمجيات المطلوبة
* نظام التشغيل: Windows 10/11 Pro
* قاعدة البيانات: PostgreSQL 14+
* بيئة التشغيل: Node.js 18+
* التحكم في النسخ: Git

## 3. خطوات التثبيت
[صورة: مخطط يوضح تدفق خطوات التثبيت]

### 3.1 إعداد قاعدة البيانات
1. تحميل وتثبيت PostgreSQL.
2. إنشاء مستخدم جديد باسم `maro_admin` وصلاحيات كاملة.
3. إنشاء قاعدة بيانات فارغة باسم `maro_db`.

### 3.2 تثبيت الخادم والعميل
1. قم بفك ضغط ملف الحزمة في المجلد الرئيسي.
2. قم بتشغيل الأمر `npm install` لتثبيت المكتبات.
3. قم بتعديل ملف `.env` ووضع إعدادات الاتصال بقاعدة البيانات.
4. تشغيل النظام عبر الأمر `npm run start`.

## 4. الشبكة والاتصال
* يجب ضبط IP ثابت (Static IP) للخادم.
* فتح المنافذ (Ports) المطلوبة في الجدار الناري (Firewall): 3000, 5432.
