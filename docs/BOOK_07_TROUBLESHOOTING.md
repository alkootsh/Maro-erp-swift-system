# كتاب 07: دليل استكشاف الأخطاء (Troubleshooting) - منصة مارو للأعمال

## 1. مقدمة
دليل لحل المشاكل التقنية الشائعة.

## 2. قائمة المشاكل والحلول
### مشكلة: تعذر الاتصال بقاعدة البيانات
* **السبب:** الخدمة متوقفة أو إعدادات الاتصال خاطئة.
* **الحل:** التأكد من تشغيل خدمة PostgreSQL وفحص ملف `.env`.

### مشكلة: قارئ الباركود لا يعمل
* **السبب:** الجهاز غير موصل أو التعريف مفقود.
* **الحل:** التأكد من التوصيل وإعادة تثبيت التعريف.
