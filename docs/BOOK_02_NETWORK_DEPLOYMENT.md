# كتاب 02: نشر الشبكة (Network Deployment) - منصة مارو للأعمال

## 1. مقدمة
تعتمد منصة مارو على بنية شبكية مرنة تدعم العمل بنظام Offline-First.

## 3. إعدادات الشبكة
* استخدام أجهزة Switch تدعم Gigabit Ethernet.
* تفعيل التشفير (VPN) للاتصال بين الفروع البعيدة والخادم المركزي.
* ضبط التزامن (Sync Engine) ليعمل تلقائياً عند استعادة الاتصال.
